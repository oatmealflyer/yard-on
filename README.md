# Yard ON (야드온)

### 컨테이너 야드 반입·반출 접수 및 현황 조회 서비스

## 1. 프로젝트 소개
Yard ON은 거래처 직원이 컨테이너 야드의 반입·반출을 접수하고, 컨테이너별 작업 현황을 조회할 수 있는 웹 서비스입니다.

거래처 사용자의 편의성을 중심으로 설계하며, React 클래스형 컴포넌트를 활용한 컴포넌트 분리, 데이터 전달, 상태 관리 및 생명주기 이해를 개발 목표로 합니다.

## 2. 주요 기능
- 거래처 로그인: 사업자등록번호 기반 모의 로그인
- 접수 내역 조회: 반입·반출 내역을 구분하여 조회
- 컨테이너 상세 조회: 보관 위치, 작업 상태, 배차 차량번호 및 반출 예정 순번 확인
- 신규 접수 요청: 반입·반출 접수 및 당일 접수 제한
- 접수 승인: 당사 직원의 수동 승인 방식 (1차에서는 모의 요청 처리)

## 3. 기술 스택
- Frontend: React (Class Components)
- Language: JavaScript
- Routing: React Router
- Styling: CSS
- Runtime: Node.js 18.18
- Development Tool: Create React App
- Data: Mock Data

## 4. 개발 범위 및 우선순위

1차 필수 기능
1. 로그인 페이지
2. 반입·반출 접수 내역 목록
3. 컨테이너별 상세 현황
4. 페이지 라우팅 및 클래스형 컴포넌트 생명주기 확인

추가 구현 기능
1. 신규 접수 페이지
2. 접수 요청 확인 및 당일 접수 제한
3. 모의 접수 요청 처리

## 5. 향후 확장 계획
- 당일 접수 문의 이력 및 당사 시스템 알림 연동
- 직원 수동 승인 및 승인 결과 조회
- 컨테이너 반입·반출 사진 조회
- 배차 정보 및 반출 순번 실시간 연동
- 접수 요청 이력 조회

## 6. 프로젝트 실행 방법

```bash
npm install
npm start
```

개발 서버: http://localhost:3000

## 7. 개발 목표
실제 물류 업무 흐름을 반영하면서 React 클래스형 컴포넌트의 Props, State, Routing 및 Lifecycle을 학습하고, 역할별 디렉터리 구조를 갖춘 웹 애플리케이션을 구현합니다.
